tmux Cheat Sheet (Short)
Assume default prefix: Ctrl+b

Start new session: tmux new -s backupseed

List sessions: tmux ls

Attach session: tmux attach -t backupseed

Detach (keep running): Ctrl+b, then d

Kill session: tmux kill-session -t backupseed

New window: Ctrl+b, then c

Next/prev window: Ctrl+b, then n / p

Rename window: Ctrl+b, then ,

Close window: exit (inside shell) or Ctrl+b, then &

Split pane vertical: Ctrl+b, then %

Split pane horizontal: Ctrl+b, then "

Move between panes: Ctrl+b, then arrow keys

Close pane: exit in that pane

Scrollback/copy mode: Ctrl+b, then [

Quit copy mode: q

Show keybindings help: Ctrl+b, then ?

For your syncoid runs
Start: tmux new -s backupseed
Run syncoid command
Detach: Ctrl+b, d
Reattach later: tmux attach -t backupseed
