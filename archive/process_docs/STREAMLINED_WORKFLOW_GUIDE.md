# Streamlined Blog Post Workflow Guide

**For 257 content sources with minimal time investment**

## The Problem You're Solving

- **257 total content sources** (149 Perplexity + 15 Claude + 14 ChatGPT + 36 finished + 43 raw posts)
- **Very little available time** - need maximum automation
- **All posts need your voice** - dictation + images + commands
- **Want to start when no more chat material** - but that's now!

## The Solution: "Quick Win" Strategy

### **Phase 1: Start with 3-5 High-Impact Posts (This Week)**

**Why start now?** You have enough material. The remaining 9 projects (SDR, PiKVM, etc.) are only 2-3 short chats each - perfect for future micro-posts.

**Choose your first 3-5 posts from:**

1. **"Network Rebuild Chronicles"** ✅ (Template created)
2. **"Server Build Journey"** (Hardware selection story)
3. **"Cable Detective Story"** (Troubleshooting methodology)
4. **"FreeBSD Router from Scratch"** (Complete setup guide)
5. **"ZFS Pool Archaeology"** (Data recovery story)

### **Phase 2: Minimal Time Investment Process**

**Per post (15-20 minutes total):**

1. **Dictate core story** (5-10 minutes)

   - Use your phone or MacBook
   - Cover: problem → exploration → solution
   - Don't worry about perfect grammar

2. **Add command examples** (5 minutes)

   - Extract from Perplexity chats
   - Include good output and error examples
   - Show troubleshooting steps

3. **Add one screenshot** (2 minutes)

   - Command output, network diagram, or result
   - Makes post feel "real" and professional

4. **Link to related posts** (2 minutes)
   - Cross-reference other posts
   - Create content clusters

### **Phase 3: Automation Tools**

**Use the created tools:**

- `minimal_post_workflow.py` - Creates post templates
- `automated_post_processor.py` - Tracks progress
- Binary state system - Clear progress tracking

## **Binary State Tracking**

Each post has 7 states:

- [x] **Dictation complete** - Your voice added
- [x] **Commands+Output** - Technical examples added
- [x] **Images** - Screenshots included
- [x] **Cross-links** - Related posts linked
- [x] **Source material** - Content integrated
- [x] **LLM weaving** - Content polished
- [x] **Editorial sign-off** - Ready to publish

**Target**: 5-6 states per post minimum
